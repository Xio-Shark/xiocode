## 一句话

**本地优先、BYOK、崩溃也不丢现场的终端 coding agent——你的代码不上传，合入权永远在你手里。**

---

## 给谁用

- 终端重度使用者，想要一个开箱即用的 coding agent
- 对代码隐私敏感、不能用云端 agent 服务的公司/个人
- 需要在多个 provider 之间自由切换的用户（DeepSeek 等国产模型一等公民支持）

---

## 用户价值（三个钩子，按可感知程度排序）

| # | 钩子 | 用户第一天就能体感什么 |
|---|------|------------------------|
| 1 | **长会话韧性** | 每一步写日志（WAL + checkpoint）。任务中 kill 进程、终端崩溃、agent 改坏：`xio resume` 原地恢复，`/rollback` 撤回文件改动 |
| 2 | **本地与隐私** | 没有云端 agent 服务、没有遥测；所有记录在 `~/.xiocode/`；任意 provider BYOK |
| 3 | **合入权在人** | 改动落地前先看 diff；可选 worktree 隔离 + 显式 `/merge` 关口；永远不自动合入 |

隔离阶梯（用户自选）：直接改当前目录（默认，不强制 git）→ opt-in git worktree + merge 关口 → 容器（规划中，等用户信号）。

**诚实边界**：worktree 保护的是主树合入，不是 OS 级沙箱；`bash` 默认可达宿主机。危险命令走确认拦截层，不靠「文档里写了」。

---

## 成熟可用的达标线（可度量）

安装一次成功、首任务 ≤ 5 分钟、成本显示真实美元、崩溃必可 resume、长会话不卡顿、危险命令有拦截、≥ 10 个真实用户且有人第二周还在用。完整定义见 [ROUTE-B-PRODUCT-PLAN.md](./ROUTE-B-PRODUCT-PLAN.md) 第一节。

## 非目标

| 非目标 | 说明 |
|--------|------|
| 「全面超越 Claude Code / Cursor」 | 不打正面「更强」；打隐私 / BYOK / 国产模型 / 韧性缝隙 |
| 云端服务与遥测 | 不上传代码或轨迹；反馈靠用户手动提交 |
| 无同意自动合入主树 | 会话与所有路径统一 merge-ask |
| 强制 git / 强制 worktree 才能启动 | 默认 direct-cwd；git 可选 |
| 默认 Docker 沙盒 | 零用户信号功能；等第一个用户说出口再议 |
| 多租户 / 云平台 / 任务 DAG 引擎 | 本地个人闭环优先 |
| 没有用户信号的功能 | 用户抱怨是唯一路线图 |

实验性面（自改进飞轮：eval / regress / improve）已移出默认叙事，CLI 保留但不再投入开发；只有真实用户主动要求时才解冻。

## 设计哲学（指针）

Harness 是模型与现实世界之间的翻译器：构造动作空间、管理上下文、不对称安全、暴露可执行错误、可观测回溯。对 XioCode，这份翻译器的第一要务是**让用户敢把真实任务交给它，且随时能回到出事之前**。历史长文见 [archive/HARNESS.md](./archive/HARNESS.md)。
